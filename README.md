# Redis-backed Map Adapter

Реализация адаптера `Map<String, String>` поверх Redis с использованием клиента Jedis.  
Цель проекта — предоставить прозрачную обёртку над Redis, соответствующую интерфейсу Java `Map`, включая поддержку основных операций чтения, записи, удаления и итерации.

---

## 📌 Основные возможности

- Полная реализация интерфейса `Map<String, String>`
- Хранение всех данных в Redis
- Использование клиента [Jedis](https://github.com/redis/jedis)
- Покрытие всех методов unit-тестами (JUnit 5)
- Поддержка запуска Redis через Docker

---

## 🛠 Используемые технологии

- Java 17
- Redis (через Docker)
- Jedis
- JUnit 5
- Gradle
